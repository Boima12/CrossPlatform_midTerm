# Đa nền tảng giữa kỳ - Cao Hoàng Phước Bảo - 23IT010

## Các bước khởi chạy dự án

1. tải các thư viện package (nếu chưa tải)

```cmd
npm install
```

<br><br>

2. cóp file `.env.example` và đổi tên thành `.env`, các cấu hình trong file `.env` em đã gửi lên trong link drive đính kèm
   <br><br>

3. chạy ứng dụng bằng lệnh

```cmd
npm start
```
